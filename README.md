# Kia Sportage 2018 — Launcher para radio Android 7.1.2 (PX3, 1024x600)

Launcher tipo tablero para un Kia Sportage 2018, basado en Clean Launcher.

## Pantalla principal
- **Velocímetro GPS** (0–240 km/h), **viaje** y **velocidad máxima** (mantén presionado VIAJE para reiniciar).
- **Satélites, altitud y rumbo** en tiempo real.
- **Sportage gris** con anillo rojo; las **luces se encienden** en modo nocturno, con la señal de luces de la radio, o al tocar el carro (mantén presionado el carro para cambiar nombre o foto).
- **Navegación** (abre Google Maps o Waze) y **música** (Spotify, Bluetooth, USB) con anterior / play / siguiente.
- **Barra inferior:** Inicio, Maps, Spotify, WhatsApp, KIA (abre Configurar), Música, Bluetooth, Auto (mantenimiento) y Apps.
- Sin voz de bienvenida.

## Compilar el APK con GitHub
1. Crea un repositorio y sube el contenido de la carpeta `KiaSportage-Launcher`.
2. Pestaña **Actions** → corre **Build APK** (o haz push a `main`).
3. Descarga `KiaLauncher.apk` desde **Artifacts** y pásalo a la radio.

Primera vez en la radio: acepta el permiso de ubicación (para velocímetro y satélites) y activa "Acceso a notificaciones" para controlar la música.
